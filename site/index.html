How it works

From chat to checkout in five steps

No wallet pop-ups, no copy-pasting gift card codes.

01

Top up once

Send shielded ZEC to a fresh Orchard address. It's credited after 1 confirmation, exactly once per deposit.

02

Ask the agent

“₹300 on flipkart.” The agent picks denominations with the least waste and the server prices the basket.

03

Click to pay

Pay from your balance, or scan a ZIP-321 QR for a single order from your own wallet.

04

Card delivered

We buy on Bitrefill and wait until the code is actually delivered, not just paid.

05

Auto-filled

On the payment page, the extension types the code and PIN into the gift-card field with real input events.

Features

Private by default. Safe by design.

Built so an AI agent can help you shop without ever being able to spend on its own.

🛡️

Shielded payments

Orchard and Ironwood transactions hide sender, receiver, amount and memo from chain observers.

🤖

Agent that can't buy

The agent only asks the server to price a basket. Every purchase needs your click. Plans are single-use and expire in 10 minutes.

🔑

Viewing-key only

The server watches deposits with a viewing key. A server compromise can't move your funds.

⚡

One-click autofill

Detects the checkout total, offers “Pay with Zcash” and fills the gift-card field. React-form safe.

🔒

Spend caps

$10 per order, $25 per day by default. Above the cap the server refuses.

♻️

Crash-safe

Every purchase step is saved before and after. A restart never buys twice.

FAQ

Questions, answered

Is this using real money?

The demo payment ran on testnet ZEC, but the Bitrefill purchase and the Flipkart card are real. Mainnet is the same code with ZCASH_NETWORK=main.

Which merchants work?

Flipkart India is verified end to end. About 24 other Indian merchants are mapped but not yet enabled.

Which browsers are supported?

Chrome and other Chromium browsers (Edge, Brave, Arc) via Manifest V3.

Why isn't it on the Chrome Web Store?

It's a hackathon build, so you install it as an unpacked extension. The download page walks you through it in under a minute.

Can the operator see my purchases?

With a prepaid balance, yes: the operator can link purchases to your wallet token. Pay by QR to avoid that.

Are withdrawals supported?

Not yet. They're manual, because the server deliberately has no spending key.
