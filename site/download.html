Download

Get the ShieldCheckout extension

Your download should start automatically. If it doesn't, use the button below.

⬇ Download shieldcheckout-extension.zip

Version 0.1.0 · Chrome / Chromium (Manifest V3)

STEP 1

Unzip

Extract the zip to a folder you'll keep, e.g. ~/shieldcheckout-extension. Chrome reads from it, so don't delete it.

STEP 2

Load unpacked

Open chrome://extensions, switch on Developer mode, click Load unpacked and pick the folder.

STEP 3

Shop

Start the server, open localhost:8787/agent, and go to a Flipkart checkout. See quickstart →
