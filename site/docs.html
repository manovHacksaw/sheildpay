Documentation

ShieldCheckout lets you pay at Indian checkouts with shielded Zcash. An agent prices your basket, buys a gift card on Bitrefill, and the Chrome extension fills it into the merchant's payment page.

Overview

"₹300 on flipkart" → agent plans basket → you click Pay → Bitrefill invoice → card delivered → extension fills checkout

Three pieces work together:

  • Server (server/): agent, pricing, ledger, Bitrefill fulfilment. Serves the chat UI at /agent.
  • Watcher (watcher/, Rust): watches the chain for deposits using a viewing key only.
  • Extension (extension/): detects checkouts and types the card code and PIN.

Install the extension

  1. Download the zip and extract it somewhere permanent.
  2. Open chrome://extensions and enable Developer mode.
  3. Click Load unpacked and select the extracted folder (the one containing manifest.json).
  4. Pin the ShieldCheckout icon from the puzzle-piece menu.

Or build it yourself:

cd extension
npm ci
npm run build      # output in extension/dist

Run the server (testnet, real cards)

Requires Node 22+, Rust stable, Chrome, a Bitrefill account with USD store credit, and a little testnet ZEC (TAZ) from a faucet.

git clone https://github.com/manovHacksaw/sheildpay && cd sheildpay

# 1. Receiving wallet (server only gets the viewing key)
cd watcher
cargo +stable run -q --example gen_wallet -- wallet-seed-testnet.txt test

# 2. Config
cd ../server && npm ci && cp .env.testnet.example .env.testnet
# edit .env.testnet: BITREFILL_API_KEY, ZCASH_UFVK

# 3. Watcher (terminal 1)
cd ../watcher && set -a && . ../server/.env.testnet && set +a && cargo +stable run

# 4. Server (terminal 2)
cd server && npx tsx --env-file=.env.testnet src/index.ts

Keep wallet-seed*.txt private. They are gitignored; never commit or share them.

Shop from chat

Open localhost:8787/agent and type what you want, for example ₹50 on flipkart. The agent lists merchants, searches the catalog and asks the server for a price. You get the cards, fee and ZEC total, plus a “fewest cards” alternative.

Then choose either:

  • Pay from balance: debits your prepaid balance and buys immediately.
  • Scan QR: a ZIP-321 URI with a fresh address for this one order.

Add funds

Click Add funds in the agent page. Send shielded ZEC to the address shown and wait for 1 confirmation (about 75 s on testnet). Each deposit is credited exactly once.

Checkout autofill

On a supported checkout (Flipkart today), the extension reads the order total and shows a “Pay with Zcash” option. Once your card is ready it fills the gift-card number and PIN using real input events, so React-controlled forms accept it.

Bitrefill sometimes delivers Flipkart cards as a redemption link instead of a code and PIN. Open the link, copy the code, and the extension can fill it in.

Configuration

Set these in server/.env.testnet (or .env for mainnet).

  • BITREFILL_API_KEY: Bitrefill REST v2 bearer key.
  • ZCASH_UFVK: unified full viewing key from step 1.
  • ZCASH_NETWORK: test or main.
  • PER_ORDER_CAP_USD (default 10), DAILY_CAP_USD (default 25).
  • ENABLED_MERCHANTS: merchants that may be sold (Flipkart today).
  • TESTNET_REAL_PURCHASES=1: opt-in for testnet ZEC buying real cards; binds to 127.0.0.1.

Set USD as your primary store-credit currency on Bitrefill. Otherwise the API reports balance: 0 and the caps will refuse every order.

Guardrails

  • The agent can only request a price. Every purchase needs your click. Plans are single-use and expire in 10 minutes.
  • Per-order and per-day caps are enforced by the server.
  • Bitrefill balance is checked before quoting.
  • Balance debits are atomic, so two clicks can't overspend.
  • Each purchase step is persisted; a restart mid-purchase halts for manual review instead of risking a double buy.
  • Card codes are masked on screen; order files are mode 600 and gitignored.

Privacy & trust

Merchants never see crypto, and chain observers see only a shielded transaction. The prepaid balance is custodial: the operator can link purchases to an account. For unlinkable payments use the per-order QR flow. Server logs and IPs are not hidden (no Tor).

Limitations

  • Demo payments ran on testnet ZEC; the cards are real.
  • Withdrawals from the prepaid balance are manual.
  • Only Flipkart is verified end to end.
  • Cards release at 1 confirmation; ZEC/USD price risk sits with the operator for the life of a quote.

Troubleshooting

Extension doesn't show “Pay with Zcash”

Make sure you're on a Flipkart payment page and the extension is enabled. Reload the tab after installing.

Server refuses every order

Check the caps and that Bitrefill's primary store-credit currency is USD.

Deposit not credited

Confirm the watcher is running and wait for 1 confirmation.
